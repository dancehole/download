## 一、需求原文（用户提出）

> download 项目里，相册管理页面（download/admin），每个相册的管理页面上方有「相册设置」「相册管理员」「空间与清理」这几个部分，能不能做成可折叠或者合并到一个独立展开页面（相册设置）里？我想保持 admin 相册的纯净。

核心诉求：**进入某个相册的管理页时，页面主体应该只服务于「上传照片 / 查看照片 / 分享链接」**，而三块偏「配置 / 权限 / 危险操作」的卡片默认不要占版面。

## 二、现状分析（代码事实）

`frontend/admin.html` → `#viewDetail`（相册管理页）当前自上而下顺序：

| 序号 | 区块 | DOM | 说明 |
|------|------|-----|------|
| 1 | 返回 + 详情头（名称 / ID / 张数 / 创建时间 / 统计 / 过期 chip） | `.detail-head` | 保留（元信息） |
| 2 | 清理提示条 | `#purgedNotice` | 仅 `local_cleared` / `oss_cleared` 时显示，平时不占位 |
| 3 | 分享链接（复制 / 打开 / 重新生成） | `.share-box` | 保留（核心） |
| 4 | **相册管理员**（列表 + 为相册创建管理员 + 授权已有账号） | `#albumAdminsCard` | 仅超管可见（`admin.js:85` / `renderAlbumAdmins()`） |
| 5 | **相册设置**（缩略图尺寸 / 使用 OSS / 相册过期时间 + 保存） | `.settings-card`（无 id） | 全部角色可见 |
| 6 | **空间与清理**（占用提示 + 清空 OSS / 删除本地照片 / 删除整个相册） | `.danger-zone` | 全部角色可见 |

即：**三块配置类卡片（4/5/6）横在上传区之前**，进相册想传照片必须先把它们滚过去；手机上尤其明显（`.danger-zone` 在 560px 以下变纵向堆叠，更高）。

- `admin.js:85` `applyRoleUI()`：`$("albumAdminsCard").hidden = !superUser`
- `admin.js:1145` `renderAlbumAdmins()`：同样控制 `#albumAdminsCard` 显隐 + 渲染管理员 chips / 授权下拉
- `admin.js:465-476` `renderDetail()`：`clearOssBtn` / `clearLocalBtn` 按 `oss_cleared` / `local_cleared` 置灰；`eventExpireSelect.disabled = !!ev.purged`；`uploadZone` 在本地已清空时 `display:none`
- `admin.js:1294-1300` 一次性绑定：`deleteAlbumBtn` / `saveEventSettingsBtn` / `clearOssBtn` / `clearLocalBtn`
- 查询串破缓存：`admin.html` 里 `admin.css` / `i18n.js` / `api.js` / `admin.js` 均为 `?v=15`
- i18n 复用键（无需新增即可用）：`event_settings`(相册设置) / `album_admins`(相册管理员) / `cleanup_title`(空间与清理) / `save`

## 三、方案

### 推荐：方案 A —— 折叠式「相册设置」面板 + 内部分段（Tab）

**页面新结构（`#viewDetail`）**

```
‹ 返回
详情头（名称 + chips）
清理提示条（仅异常时出现）
分享链接卡片                      ← 纯净版到此为止
────────────────────────────────
⚙ 相册设置  ［收起 ▸］             ← 新增：一行折叠头（默认收起）
   ├ 展开后：分段标签  [基本设置] [相册管理员] [空间与清理]
   │   · 基本设置：缩略图尺寸 / 使用 OSS / 相册过期时间 / 保存
   │   · 相册管理员（仅超管，非超管该分段整段隐藏）：名单 + 创建 + 授权
   │   · 空间与清理：占用提示 + 三个危险按钮（红框块）
────────────────────────────────
上传照片（JPG / RAF）
已上传照片
```

- 折叠头右侧带**状态摘要**（收起时也能一眼看到关键信息，例：`过期 2026-09-20 ／ 本地 12.4GB`），点任意处展开/收起。
- **默认收起**；切换相册时自动收起；不写 localStorage（保证每次进相册都干净）。
- 三个分段一次只显示一个 → 面板高度可控，危险操作被收进「空间与清理」分段，降低误点。
- 采用 `<button aria-expanded aria-controls>` + 原生 hidden，无新依赖，纯 CSS + 少量 JS。
- 超管/相册管理员差异：非超管只看到「基本设置 / 空间与清理」两个分段（相册管理员分段整段隐藏，含 tab 按钮）。

**为什么不是「整块搬到最底部」**：照片多时底部要滚很久，配置入口会变得难找；折叠头放在分享链接下方，收起时只占约 48px 一行。

### 备选：方案 B —— 独立「相册设置」子页面

点详情页「相册设置」按钮 → 切到独立视图（类似现有 `#viewSettings`），页内三分段，左上「‹ 返回相册」。
优点：相册页最纯净（连一行都没有）。缺点：配置与照片上传需要来回切换，续期/清理后回到上传要多两次点击。

### 备选：方案 C —— 三块各自独立折叠（3 个折叠头）

改动最小，但收起后仍有 3 行标题占版面，「纯净」效果不如 A；且展开多个时页面照样很长。

## 五、验收标准

1. 进入 `/download/admin` 任意相册：默认看不到三块配置卡片，页面为「详情头 + 分享链接 + 上传 + 照片」。
2. 点「相册设置」：面板展开，默认落在「基本设置」；再点收起，状态往返正常。
3. 切换相册 / 刷新页面：面板回到收起状态。
4. 「基本设置」保存成功；「空间与清理」三个按钮的禁用状态与清理后行为与现在一致；「相册管理员」仅超管可见，创建/撤销照旧。
5. 手机（375px 视口）无横向溢出，分段标签可滑动/换行。
6. 中英文切换正常，`?v=16` 生效（无旧缓存）。
7. CDP 端到端脚本全绿，浏览器控制台无报错。
